## Eric's ruling (2026-11-03): how the Rust port and the language packs catch up

1. The Rust engine catches up closely once Java has a new release, because Java is the reference implementation.
2. The Python and Node.js language packs catch up with the Java engine when functionality crosses from the engine to
   the packs (telemetry, AI SDLC and the like). Their version may therefore not catch up as closely as Rust's does.

Both still carry the Java release number they caught up to and never run a sequence of their own
(`conv-ports-adopt-java-release-number`, 2026-09-16). The ruling says when each catches up.
