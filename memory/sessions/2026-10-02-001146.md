## Decisions Made

- Claude-only helper; the contract stays provider-neutral through `params.provider`. Default model stays `claude-opus-5-5` (Eric kept it after
  seeing Haiku's smoother cadence), documented with the Haiku alternative; the demos ask for 2000 tokens because Opus thinks before it answers
  and thinking tokens count against `max_tokens` (a 48-call live probe found no empty result at the old budgets either).
- Progressive rendering is never buffered: each batch is its own segment, pinned by a test.
- A reply with nothing usable is a 422, never an empty success; the contract is stricter than the demo nodes were (a `params` allowlist, a
  schema on `llm.stream` is a 400); both are READ items in the CHANGELOG.
- AWS Bedrock through IAM is the planned second backend: the `Backend` seam is documented, not built.
- Each example app lives in a folder of its own with a README and `resources/`; the Node pack mirrors it.
