## What was done

- **`src/mercury_composable/rest_routing.py`** - the pure half: `RoutingTable.load` with the engines' messages
  (`rest[0] missing 'service'`, `rest[0] unknown cors id 'nope'`, the cors line rules, the static-content block)
  and the pack's own refusals by name (a flow binding, the HTTP relay, the A/B dual service, `upload`); the
  default entries merged when the file does not claim their URLs; `find` with the engines' precedence (a
  non-wildcard entry beats a wildcard one, then more literals; `OPTIONS` matches any entry; a trailing `*` needs a
  segment; a mid-path `*` one segment; a `v*` prefix); `path_matches_any_method` for the 405; `retain_available`
  for the load-time skip; `HeaderTransform` (keep over drop, the Java rule); `parse_timeout` (clamped 1 s - 5 min);
  `parse_body` by content type; `parse_query` (a repeated key a list), `parse_cookies`; `accept_fallback_type`,
  `negotiate_stream_type`; `render_payload` (pretty JSON, nulls omitted, the HTML shell); `map_response` (the
  standard error body for a failure, the `my_*` and streaming handles withheld, `set-cookie` split on `|`, the
  transform, the correlation-id echo, the CORS headers, no body for HEAD).
- **`src/mercury_composable/async_http_request.py`** - `AsyncHttpRequest`: the engines' map keys in `to_map()`
  (`parameters` always with both sub-maps, `cookies` and `session` only when present, a body set to None kept) and
  the accessors a function reads the map with (`path_parameter`, `query_parameter`, `query_parameters`, `header`,
  `cookie`, `session_info`, `timeout_seconds` where `x-ttl` wins). Exported from the package.
- **`src/mercury_composable/rest_automation.py`** - the edge: the switch and the file location (`classpath:` the
  resources folder, `file:` absolute, else under the application folder; a missing or empty file degrades to the
  defaults with a warning), `${ENV:default}` resolved in every value; an aiohttp middleware ahead of the host's
  routes: the match, the `/` fallback to a declared `/index.html`, the 405, the preflight (405 without CORS), the
  built-in services (`event.api.service` and the five actuators by the engines' names, behind the entry's
  authentication and timeout, with its CORS headers), the function path (`_prepare`: the request transform, a W3C
  `traceparent` first with its span as the edge's parent, the trace-id header next, a fresh id under `tracing`, the
  custom traceparent name read only when the standard is absent, the correlation id ensured and stamped, `x-ttl`
  stamped unless sent, the cookie header withheld into the map), authentication by RPC, the RPC through the bus
  with the edge's span as the parent and the round-trip record on the edge, an interceptor through a reply sink
  (the first event the whole reply without `stream: true`; with it the SSE or chunked renderer with keep-alive
  pings, the idle timeout in band, the error frame), and the static folder under the `static-content` rules (the
  filter with a 10 s wait, its headers copied, a non-200 passed through, a failure serving the file; the no-cache
  headers for the entry pages). The edge records `http.request` with the caller's span as its parent. A response
  without a negotiated content type carries none, where aiohttp would add `application/octet-stream`.
- **`server.py`**: the table loaded at construction (a misconfigured entry fails the start), the middleware
