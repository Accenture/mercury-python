## Lesson

A shell variable set for one command (`NAME=value python3 ...`) is not in the environment of the heredoc script for a second
variable set the same way without exporting it: the fact's footer was written and the log was not, and the stamp had to be
read back from the footer. Export what a script reads, or pass it on one line.
