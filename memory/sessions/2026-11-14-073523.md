## What was built

- **`extensions/mcp-binding/mcp_binding.py`** on the official MCP SDK 2.x (snake_case fields; `streamable_http_client`;
  the server class is `MCPServer`). Servers by name in `resources/mcp-servers.yml` (`mcp.servers` names the file):
  `stdio` (a command this process starts with the SDK's minimal environment plus the `env` variables listed) or `http`
  (a streamable HTTP URL with `headers`); `${VAR}` references resolve at boot through `AppConfig.resolve_text` and
  are never logged; an allowlist maps each remote tool to a route and the SHA-256 of its input schema in canonical JSON
  (keys sorted, no spaces, Unicode kept). Boot (inside the serving loop, before the first request) connects each server
  in a task of its own - the SDK's transports run in anyio task groups whose cancel scopes must be entered and left on
  one task - lists its tools, verifies the allowlist and registers one route per tool with `default_registry.register`;
  a failure stops the application by name (`SystemExit(1)`), the exception group unwrapped to its leaf. A route's body
  is the arguments; the reply is `structured_content` else the content blocks' text; `is_error` → 400 with the text,
  a timeout → 408, a protocol error → 502, no session → 503. `describe [server]` prints each tool's digest and a catalog
  row for the graph. `mcp.health` (private) reports the servers and their connections.
- **`Platform.on_startup` / `on_cleanup` / `create_app`** in `src/mercury_composable/server.py`: async callbacks attached to
  the aiohttp application's lifecycle, `run` unchanged for every other application.
- **The `mcp` extra** (`mcp>=2,<3`) in `pyproject.toml`, also in `dev`.
- **Tests:** `tests/test_mcp_binding.py` (46 cases) - the shared vector file `tests/vectors/mcp-binding-vectors.json`

## Lessons

- The MCP SDK 2.x wraps a plain return of a tool as structured content (`{"result": ...}`) unless the tool declares
  `structured_output=False`; the binding prefers structured content, which is the contract - the fixture declares it.
- A stdio subprocess inherits a stderr file descriptor: hand it `sys.__stderr__`, since a replaced `sys.stderr` (a test's
  capture) has none.
- Python 3.10 compatibility: unwrap exception groups by duck typing (`.exceptions`), not by the 3.11 builtin's name.
