## Defaults set without a ruling (for the spec's build notes and Eric's review)

1. **Hidden entries are invisible to every file tool** unless `tools.file.hidden=true` - the spec said it for
   `file.list`; a `.env` or `.git` inside the workspace must not be readable by default either.
2. **The resolved address is pinned:** the host is resolved, every address checked against the ranges, and the request
   goes to the checked address with the `Host` header and TLS `server_hostname` set, so a second resolution cannot
   point elsewhere (DNS rebinding). The check covers IPv4-mapped IPv6 addresses.
3. **A write is bounded by `tools.file.max.bytes`** as a read is; a crawl's whole text by 60 000 characters (under the
   loop's default `llm.run.result.limit`); `max_depth` is capped at 5; the page's own status (404, 500) is a result.
4. **No row sets `strict`:** every row has optional properties, and whether a grammar-constrained schema may carry
   them is the model's and the API's; the graph's author adds it. Every row closes its object (`additionalProperties:
   false`) and the tool refuses an unknown argument by name.
5. **Statuses:** 400 a refusal naming the rule and the key, 404 a missing file or folder, 408 a timeout, 409 an
   existing file under `create`, 502 an unresolvable host or a failed connection.
6. **Row names are the routes with `_` for `.`** (`file_read` for `file.read`), pinned by a test.
