## Lesson

A batch edit script that reads a file once per replacement and writes at the end lets the last replacement overwrite
the earlier ones of the same file; two of four edits were lost that way and re-applied. Chain replacements on one
in-memory text per file, or write after each.

## Second improvement: route aliases in `@preload` (Eric verified the first one manually, then asked for this)

The Java engine's `@PreLoad(route = ...)` takes one route name or a comma-separated list, every name registered as
the same function (`AppStarter.preload`: `util.split(svc.route(), "[, ]")`, then `platform.register(r, f, instances)`
per route, the same visibility); the Python decorator took one name, and a list failed as an invalid route name.

- `src/mercury_composable/registry.py`: `split_routes(route)` splits on commas and whitespace as the engine does,
  drops empty segments, validates every name, keeps a repeated name once (order kept) and refuses a value with no name
  with the engine's words (`missing service route(s)`); `preload` splits at decoration and registers each name with the
  same handler, `instances`, `private` and `interceptor`. `FunctionRegistry.register` stays single-route, as the
  engines' `Platform.register` does (the MCP binding registers its aliases through it, one call per route); each alias
  has its own mailbox and workers, its own startup line and its own `/info/routes` row, the engines' shape; a function
  reads the alias it was called as from `get_trace().route` (the engines' `my_route`, as the MCP binding does).
- `tests/test_registry.py` (new, 9 tests): the split (one name, lists with and without spaces, a space alone, empty
  segments, a repeated name), the refusals (no name; an invalid name in the list; `register` given a list), the
  decorator on a fresh registry (both routes the same function with the same instances and visibility, a local RPC to
  each alias answered with that alias in `get_trace().route` and as sender) and an empty list refused at decoration.
- `examples/demo-app/demo_app.py` (Eric's direction): the `hello_world` function he had drafted is removed and
  `declarative_echo` is declared `@preload(route="hello.declarative, hello.world", instances=10)`; the demo README's
  table shows the alias; the README's function contract, `docs/guides/function-patterns.md` and the agent guide's rules
  gain the alias sentence; CHANGELOG Unreleased > Added 4 (upgrade note: none).
